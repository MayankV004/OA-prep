## Concept

Binary search works on any **monotone** structure — not just sorted arrays. The key is identifying a predicate that transitions from `False` to `True` exactly once. You then find that boundary.

> **Key insight**: Think in terms of `feasible(mid)` — a function that returns `True` or `False`. Binary search finds the exact boundary.

## Template

### Exact Search

```python
def binary_search(arr: list[int], target: int) -> int:
    left, right = 0, len(arr) - 1

    while left <= right:
        mid = left + (right - left) // 2   # avoids overflow

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

### Lower Bound (First position where arr[i] >= target)

```python
def lower_bound(arr: list[int], target: int) -> int:
    left, right = 0, len(arr)             # right = n (open boundary)

    while left < right:
        mid = (left + right) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid                   # could be the answer, keep it

    return left                           # first index >= target
```

### Binary Search on Answer

```python
def binary_search_answer(nums: list[int], days: int) -> int:
    def feasible(capacity: int) -> bool:
        """Can we ship all packages within `days` days with this capacity?"""
        ships = 1
        load = 0
        for w in nums:
            if load + w > capacity:
                ships += 1
                load = 0
            load += w
        return ships <= days

    left = max(nums)          # minimum possible capacity
    right = sum(nums)         # maximum possible capacity

    while left < right:
        mid = (left + right) // 2
        if feasible(mid):
            right = mid       # try smaller
        else:
            left = mid + 1    # must be larger

    return left
```

### Search in Rotated Sorted Array

```python
def search_rotated(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        if nums[mid] == target:
            return mid

        # Determine which half is sorted
        if nums[left] <= nums[mid]:             # left half is sorted
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:                                   # right half is sorted
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1

    return -1
```

## When to Use

- Searching in a **sorted** (or rotated-sorted) array
- Finding the **first/last** occurrence of a value
- Minimizing/maximizing a value where checking feasibility is O(n) or less
- The search space is **implicitly ordered** (answer space problems)

## Complexity Analysis

| Variation | Time | Space |
|-----------|------|-------|
| Exact search | O(log n) | O(1) |
| Lower / upper bound | O(log n) | O(1) |
| Binary search on answer | O(n log n) | O(1) |

## Common Pitfalls

- `left + (right - left) // 2` to avoid overflow (less critical in Python)
- Using `left <= right` for exact search; `left < right` for boundary search
- Correctly identifying the feasibility condition direction (minimize vs maximize)
