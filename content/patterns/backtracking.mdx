## Concept

Backtracking is a **DFS + undo** strategy. You make a choice, recurse into that choice, then **undo** (backtrack) and try the next option. The art is in writing a good **pruning condition** that cuts branches early.

> **Key insight**: Backtracking = DFS on a decision tree. Each node is a partial solution; leaves are complete solutions or dead ends.

def backtrack(state, choices):
    if is_solution(state):
        record(state)
        return

        if is_valid(choice, state):
            make_choice(state, choice)      # apply
            backtrack(state, next_choices)  # recurse

### Permutations

```python
def permutations(nums: list[int]) -> list[list[int]]:
    result = []
    used = [False] * len(nums)

    def backtrack(path: list[int]):
        if len(path) == len(nums):
            result.append(path[:])
            return
        for i, num in enumerate(nums):
            if used[i]:
                continue
            used[i] = True
            path.append(num)
            backtrack(path)
            path.pop()
            used[i] = False

    backtrack([])
    return result
```

### Subsets / Combinations

```python
def subsets(nums: list[int]) -> list[list[int]]:
    result = []

    def backtrack(start: int, path: list[int]):
        result.append(path[:])             # every path is a valid subset
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)         # i+1: no re-use of same element
            path.pop()

    backtrack(0, [])
    return result
```

### N-Queens

```python
def solve_n_queens(n: int) -> list[list[str]]:
    cols = set()
    diag1 = set()   # row - col
    diag2 = set()   # row + col
    result = []
    board = [['.' ] * n for _ in range(n)]

    def backtrack(row: int):
        if row == n:
            result.append([''.join(r) for r in board])
            return
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue
            cols.add(col); diag1.add(row - col); diag2.add(row + col)
            board[row][col] = 'Q'
            backtrack(row + 1)
            cols.remove(col); diag1.remove(row - col); diag2.remove(row + col)
            board[row][col] = '.'

    backtrack(0)
    return result
```

## When to Use

- You need to enumerate **all** valid configurations (permutations, combinations, subsets)
- Problem has a **decision at each step** with a validity check
- Greedy doesn't work because a locally valid choice may lead to a dead end
- Grid/graph path problems where you must **undo** movement

## Complexity Analysis

| Problem | Time Complexity |
|---------|----------------|
| Permutations of n | O(n × n!) |
| Subsets of n | O(n × 2ⁿ) |
| N-Queens | O(n!) |

## Common Pitfalls

- Not copying the `path` when adding to results (`result.append(path[:])` not `path`)
- Forgetting to undo **all** state changes (sets, arrays, booleans)
- Missing duplicate-skipping logic for problems with duplicate inputs
